# α 原生 Windows Markdown 编辑器

这是原生 C# / WPF 工程，不使用 HTML、Electron 或 WebView。

## v1.2.4：滚轮灵敏度

- 顶部新增“滚轮”菜单，可选择舒缓、标准、快速三档。
- 默认使用舒缓档，降低向下翻页时一次滚动过远的问题。
- 编辑区与预览区统一生效，并保存上次选择。
- 触控板和高精度滚轮按 Delta 比例滚动，双向同步仍使用低频合并。

详细说明见 `WHEEL_SENSITIVITY_UPDATE.md`。

## v1.2.3：轻量动画与滚动优化

- 移除预览同步滚动的 16ms 逐帧插值动画，改为合并后直接定位。
- 编辑区到预览区按约 55ms 合并同步，预览区到编辑区按约 75ms 合并同步。
- 同步任务使用后台优先级，优先保证输入、光标和界面响应。
- 避免程序滚动触发反向同步，减少 FlowDocument 与 AvalonEdit 循环布局。
- 导航高亮时不再持续调用 `BringIntoView`，仅主动跳转时滚动导航栏。
- 拖动滚动条时启用延迟滚动，减少大型文档的重复排版。
- 移除按钮按下时的缩放变换，保留圆角、悬停和按压反馈。

## v1.2.2：LaTeX 长箭头兼容修复

- 修复原生预览中 `\longrightarrow` 被 WPF-Math 报为未知命令的问题。
- 在原始公式解析失败时，自动对常见长箭头与逻辑箭头命令使用兼容别名。
- Markdown 源码与 HTML 导出内容保持原样，只调整原生 WPF 预览及 PDF 渲染输入。
- 支持的兼容命令包括 `\longrightarrow`、`\longleftarrow`、`\longleftrightarrow`、`\Longrightarrow`、`\Longleftarrow`、`\Longleftrightarrow`、`\longmapsto`、`\implies` 和 `\iff`。

详细说明见 `LATEX_COMPATIBILITY_UPDATE.md`。

## v1.2.1：流畅度优化

- 实时预览改为按文档大小自适应延迟，连续输入时不重复渲染。
- 纯编辑模式下暂停预览渲染，切回分栏或预览时再更新。
- 最近 4 个中小型文档缓存原生预览，标签页切换更快；超大文档不缓存以控制内存。
- 双向滚动事件限制为约 30 次/秒，动画仅在需要时运行。
- 阅读导航仅在标题结构变化时重建，并使用二分定位当前章节。
- 代码高亮正则、LaTeX 校验与本地图片均加入缓存。
- 字数统计改为延迟单次扫描，应用状态由每 2 秒写入改为有变化时每 8 秒保存。

详细说明见 `PERFORMANCE_UPDATE.md`。


## v1.2.0：阅读导航

- 自动提取当前 Markdown 文档中的 H1–H6 标题
- 点击目录项跳转到对应编辑位置
- 编辑器滚动或光标移动时自动高亮当前章节
- 顶部“导航”按钮控制显示/隐藏，快捷键 `Ctrl+Shift+O`
- 导航栏可拖动调整宽度，并记住显示状态

## v1.1.8：多文档标签页

- “打开”支持多选，一次打开多个 `.md`、`.markdown` 或 `.txt` 文件。
- 顶部标签页可切换和单独关闭，未保存标签显示圆点。
- `Ctrl+Tab` / `Ctrl+Shift+Tab` 切换标签，`Ctrl+W` 关闭当前标签。
- 支持一次拖入多个文件，并在重启后恢复上次打开的已保存文件。

## 最简单的生成方式

阅读 `CLOUD_BUILD_GUIDE.md`，使用 GitHub Actions 云端生成：

- `α.exe` 便携版
- `α-Markdown编辑器-Setup-x64.exe` 安装版

本机无需安装 Visual Studio、.NET SDK 或 Inno Setup。

## 主要功能

- Markdown 原生编辑与预览
- LaTeX 数学公式
- 代码语法高亮
- 双栏同步滚动
- 打开、保存与另存为
- PDF 打印输出
- 深色与浅色主题

## 技术组成

- .NET 8 / WPF
- AvalonEdit
- Markdig
- WpfMath

第三方组件说明见 `THIRD-PARTY-NOTICES.md`。

## v1.1.3 云端构建更新

GitHub Actions 已升级到 Node.js 24 兼容版本：`actions/checkout@v6` 与 `actions/upload-artifact@v6`。详情见 `NODE24_FIX.md`。


## v1.1.4 界面更新

顶部视图与主题控制已固定右对齐；第二行 Markdown 格式工具栏支持按钮或 F10 折叠，并记忆上次状态。




## v1.1.7 圆角按钮更新

主工具栏按钮采用 8px 圆角模板，并补充悬停、按下、键盘焦点和禁用状态。WPF 使用 `CornerRadius`，HTML 预览使用 `border-radius`。

## v1.1.6 导出菜单更新

- 顶部原有“导出 HTML”和“导出 PDF”两个按钮已合并为“导出 ▾”。
- 下拉菜单保留 HTML 与 PDF 两种导出方式。
- 快捷键保持不变：`Ctrl+Shift+H` 导出 HTML，`Ctrl+Shift+P` 导出 PDF。
- 顶部主工具栏更加紧凑，右侧视图控制区域不变。

## v1.1.5 插入菜单更新

第二行格式工具栏已移除。标题、文字样式、引用、列表、链接、图片、代码块、数学公式和表格统一收纳到顶部主工具栏的“插入”下拉菜单；查找保留为顶部独立按钮。


## v1.2.0 双向同步滚动

- 编辑区滚动时，预览区跟随。
- 预览区滚动、拖动滚动条或使用键盘翻页时，编辑区跟随。
- 阅读导航可通过顶部“导航”按钮、侧栏 × 或 Ctrl+Shift+O 隐藏。


## v1.2.5 菜单美化

- 导出面板改为带说明的列表式弹层
- 导航侧栏与按钮采用更统一的圆角风格


## v1.2.6 启动修复
